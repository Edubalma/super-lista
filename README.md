# Super Lista

PWA de lista de compras con total en vivo y presupuesto (React + TypeScript + Vite + Dexie).

## Requisitos
- Node.js 20 o superior

## Uso
```bash
npm install
npm run dev      # desarrollo: http://localhost:5173
npm run build    # compilación de producción en /dist
npm run preview  # sirve /dist localmente
```

Los montos se guardan en centavos (enteros). Los datos viven en IndexedDB del dispositivo.
